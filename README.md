# 뚝딱 (Tukk-Tak)

> 코드 없이, AI의 도움과 몇 번의 클릭만으로 요식업 사장님이 직접 홍보용 가게 홈페이지를 만들고 배포할 수 있게 하는 서비스

- **로고**: 도깨비 방망이
- **메인 컬러**: 주황 / 갈색 계열

## 프로젝트 개요

- **팀 구성**: 프론트엔드 2명, 백엔드 2명
- **프로젝트 기간**: 2026.09.16 ~ 2026.12.11
- **주요 일정**: 기획 → 개발 환경 구축 → 개발 → 성능개선 → 운영·유지보수 → 결과 보고서 작성
- **기술스택**: 추후 개발 환경 페이지에 정리 예정

## 기획 배경

동네 식당, 카페, 분식집 같은 소규모 요식업 사장님들은 가게 정보와 메뉴, 위치, 영업시간 등을 소개할 가게 소개 페이지(인포 사이트)가 필요하지만, 제작 업체에 맡기면 비용 부담이 크고 직접 만들자니 개발 지식과 디자인 감각이 없어 막막합니다.

업종·분위기 같은 컨셉만 입력하면 AI가 메뉴판, 위치, 영업시간 등을 담은 페이지 초안을 만들어주고, 사장님은 가게 정보를 채우고 디자인을 조정하기만 하면 자신만의 가게 소개 페이지를 바로 배포할 수 있는 서비스입니다.

## 핵심 기능

1. **AI 홈페이지 초안 생성** — 업종/분위기/컬러/메뉴 수 등을 입력하면 AI가 사이트 구성을 자동 생성 (백그라운드 진행)
2. **블록 조립형 사이트 에디터** — 헤더/히어로/메뉴판/갤러리/푸터 블록을 조립, 툴바로 스타일 조정
3. **간편한 배포와 관리** — 미리보기 후 원하는 링크명으로 배포, 블록 단위 수정 및 임시저장
4. **사업자 인증** — 사업자 등록증 인증 완료 회원만 배포 가능
5. **사장님 커뮤니티** — 사이트 소개 및 사장님 간 교류 공간

## 폴더 구조

이 프로젝트는 **Feature-Sliced Design(FSD)을 간소화한 구조**를 따릅니다. 블록 컴포넌트가 에디터와 배포된 실제 가게 사이트 양쪽에서 동일하게 렌더링되어야 하기 때문에, "도메인 모델 + 기본 렌더링"을 담당하는 `entities` 레이어를 `features`/`widgets`와 분리합니다.

```
src/
  app/          ← Next.js App Router. 라우팅 파일만 존재, 로직 없음.
  widgets/      ← 여러 feature/entity를 조립한 완성된 UI 블록
  features/     ← 사용자의 "행동" 단위 (로그인하다, 좋아요를 누르다, 블록을 추가하다)
  entities/     ← 도메인 "모델"과 그 모델의 기본 렌더링 (User, Block, Site, Post, Plan)
  shared/       ← 도메인과 무관한 공통 자원 (버튼, 인풋, API 클라이언트, 유틸, 컬러 토큰)
```

**import 방향**: `app → widgets → features → entities → shared` (역방향 import 금지)

자세한 레이어 규칙, 판단 기준, 체크리스트는 [`docs/folder-structure-guide.md`](./docs/folder-structure-guide.md)를 참고하세요. AI 코딩 어시스턴트(Claude Code, Cursor 등)로 작업할 때도 이 문서 기준을 따릅니다.
