# 사이트 테마(ThemeConfig) 규칙 — 백엔드 전달용

사이트 데이터의 `theme`에 들어가는 값입니다. 사이트 전체에 한 번에 적용되는 디자인 값이며,
화면은 이 값만으로 색, 모서리 둥글기, 글꼴을 정합니다.

## 저장하는 값 (8개)

```ts
interface ThemeConfig {
   bg?: string; // 배경색
   text?: string; // 글자색 (제목, 본문)
   textMuted?: string; // 보조 글자색 (설명, 푸터 정보, 저작권)
   border?: string; // 테두리색 (카드 테두리, 푸터 구분선)
   surface?: string; // 카드 배경색
   primary?: string; // 포인트 색 (강조 특징 뱃지, 메뉴 가격, 푸터 링크 마우스 오버)
   radius?: string; // 카드와 사진의 모서리 둥글기
   font?: string; // 사이트 전체 글꼴 id
}
```

| 키        | 형식                       | 예시        | 비고                                |
| --------- | -------------------------- | ----------- | ----------------------------------- |
| bg        | HEX                        | `#fff9f3`   | 아래 "색 형식" 참고                 |
| text      | HEX                        | `#352d25`   |                                     |
| textMuted | HEX                        | `#76664f`   |                                     |
| border    | HEX                        | `#c3b099`   |                                     |
| surface   | HEX                        | `#ffffff`   |                                     |
| primary   | HEX                        | `#7e654b`   |                                     |
| radius    | 숫자 + `px` 문자열         | `"12px"`    | 편집 화면에서 고르는 범위는 0~24px  |
| font      | 아래 6개 id 중 하나 (문자) | `noto-sans` | 목록에 없는 값이면 기본 글꼴로 표시 |

### 색 형식

- `#` + 16진수 3, 4, 6, 8자리를 모두 받습니다. (`#abc`, `#abcd`, `#aabbcc`, `#aabbccdd`)
- 편집 화면은 항상 `#rrggbb` 소문자 6자리로 저장합니다.
- 서버 렌더링 때 값이 style 속성에 그대로 들어가므로, 위 형식이 아닌 값은 저장하지 말고 거절해 주세요.
  (화면에서도 형식이 맞지 않으면 기본값으로 대체합니다)

### 글꼴 id

| id            | 글꼴           | 느낌                |
| ------------- | -------------- | ------------------- |
| `noto-sans`   | Noto Sans KR   | 고딕 (기본)         |
| `noto-serif`  | Noto Serif KR  | 명조                |
| `gowun-dodum` | Gowun Dodum    | 부드러운 둥근 고딕  |
| `gaegu`       | Gaegu          | 손글씨              |
| `jua`         | Jua            | 굵고 둥근 제목체    |
| `do-hyeon`    | Do Hyeon       | 두껍고 힘 있는 고딕 |

- 서버에서는 위 6개 id만 받도록(enum) 검증해 주세요.
- 글꼴은 사이트 전체에 하나만 적용됩니다. (제목/본문 구분 없음)

## 모든 키는 선택값

- 키가 없거나 형식이 맞지 않으면 화면이 기본값으로 채웁니다. 그래서 `theme: {}`도 정상입니다.
- 기본값: `bg #ffffff`, `text #1f2937`, `textMuted #6b7280`, `border #d1d5db`, `surface #ffffff`,
  `primary #374151`, `radius 6px`, `font noto-sans`
- 저장할 때는 가능하면 8개 키를 모두 보내는 편이 좋습니다.

## 저장하지 않는 값

다음은 위 값에서 화면이 계산하므로 저장하지 않습니다.

- 포인트 색 위에 올리는 글자색 (`onPrimary`는 없어졌습니다. 이미 저장된 값이 있어도 무시합니다)
- 뱃지의 연한 배경처럼 `primary`에서 파생되는 색
- 글꼴 id에 해당하는 실제 `font-family`

블록 안의 개별 설정(헤더 로고 크기, 줄글 정렬, 사진 크기 등)은 `theme`가 아니라 각 블록의
`content`에 들어갑니다. (`docs/editor-block-rules.md` 참고)

## 편집 화면의 동작 (참고)

- 색 6개는 서로 독립이며, 한 색을 바꿔도 다른 색이 자동으로 바뀌지 않습니다.
- 색이 읽기 어려워도(대비가 낮아도) 사용자가 고른 색이면 그대로 저장합니다. 서버에서 막지 않아도 됩니다.
- 템플릿으로 사이트를 만들면 템플릿의 `theme`가 처음 값으로 들어갑니다. (템플릿마다
  색과 둥글기가 다르고, 글꼴은 모두 `noto-sans`)
