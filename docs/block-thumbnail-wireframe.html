블록·구조 썸네일 와이어프레임

섹션 구조 탭의 "어떤 블록을 추가할까요?"와 "구조를 골라 주세요"에 쓸 예시 이미지 제안입니다. 실제 블록(렌더러)의 배치를 단순한 도형으로 그렸고, 승인되면 같은 모양으로 코드(SVG 컴포넌트)를 만듭니다. 썸네일은 3:2 비율입니다.

반폭 가능 전체 폭 전용

1. 블록 선택: 어떤 블록을 추가할까요?

블록 종류를 대표하는 구조 하나를 골라 그렸습니다. 문구 중 줄글·목록·갤러리 설명은 피그마 그대로이고, 헤더·히어로·푸터 설명은 제안입니다. (헤더와 푸터는 이미 있으면 비활성입니다.)

사이트에 헤더·푸터가 없을 때

헤더·푸터가 이미 있을 때

2. 구조 선택: 구조를 골라 주세요

블록을 고르면 나오는 화면입니다. 구조 이름과 태그는 현재 렌더러 기준입니다. 피그마의 줄글 "강조 문구형"은 현재 블록에 없고, 갤러리의 "단일 액자형"은 피그마에 없어서 이 화면에서는 현재 블록 기준으로 그렸습니다.

3. 페이지 구성의 드래그 표시 (참고)

블록을 드래그하는 동안 각 줄의 오른쪽에 나타나는 표시입니다. 주황은 그 줄 옆에 놓아 나란히 만들 수 있는 곳, 빨강은 놓을 수 없는 곳입니다. 빨강 문구는 상황에 따라 두 가지로 나눠 제안합니다.
