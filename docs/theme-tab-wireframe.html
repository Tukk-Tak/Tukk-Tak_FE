사이트 테마 탭 예상 화면

지금까지 정한 내용으로 그린 예상 화면입니다. 오른쪽 패널을 직접 눌러 보세요. 색 원을 누르면 색 선택 창이 열리고, 글꼴 카드와 둥글기 슬라이더도 왼쪽 미리보기 사이트에 바로 반영됩니다. (글꼴은 인터넷에 연결되어 있어야 실제 글씨체로 보입니다.)

이번에 반영한 결정
  • 색 항목은 6개(배경, 글자, 보조 글자, 테두리, 카드 배경, 포인트)이고, 모두 직접 고릅니다.
  • 기본 팔레트(무지개 색)는 없습니다. 항목마다 현재 색 원을 누르면 색 선택 창이 열립니다.
  • 색 선택 창 아래에는 "이 사이트에서 쓰는 색"(다른 항목에 쓴 색)이 나와서 같은 색을 다시 고르기 쉽습니다.
  • 각 항목에 [기본값으로]가 있고, 아래 [템플릿 색으로 되돌리기]는 처음 불러온 색으로 되돌립니다.
  • 둥글기 슬라이더가 있고, 글꼴은 6종 중 하나를 골라 사이트 전체에 적용합니다. (기본: Noto Sans KR)
  • 색 항목에 경고는 없습니다.
